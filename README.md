# CASE 15 — Telecom Management System

Оқу жобасы: **қазақша веб-сайт + Node.js/Express сервері + PostgreSQL базасы (15 кесте)**.

## Қажетті бағдарламалар
- Node.js 18+ (ұсыныс: LTS)
- PostgreSQL 14+ және pgAdmin 4
- VS Code

## 1. Дерекқорды дайындау
1. pgAdmin 4 ашыңыз, PostgreSQL серверіне қосылыңыз.
2. `Databases` → `Create` → `Database` → атауы: `telecom_case15`.
3. Жаңа базаны таңдап `Query Tool` ашыңыз.
4. Файлдарды **осы ретпен** орындаңыз (әрқайсысын ашып Execute/F5 басыңыз):
   - `sql/01_schema.sql`
   - `sql/02_sample_data.sql`
   - `sql/03_business_functions.sql`
5. Қосымша дайын SQL аналитиканы көру үшін `sql/04_analytics.sql` файлын бөлек орындауға болады.
6. `sql/05_demo_operations.sql` — тестке арналған операциялар; оны бірден орындау міндетті емес, ол деректерді өзгертуі мүмкін.

**Маңызды:** SQL скрипттерді жаңа, бос базаға бір рет орындаңыз.

## 2. Сайтты іске қосу
1. VS Code-та `CASE15_Telecom_Web` папкасын `File → Open Folder` арқылы ашыңыз.
2. `.env.example` файлының **көшірмесін** `.env` деп атаңыз.
3. `.env` ішінде `YOUR_PASSWORD` орнына PostgreSQL `postgres` қолданушысының паролін жазыңыз. Егер парольде `@`, `#`, `/`, `:` сияқты символдар болса, URI үшін кодтаңыз немесе балама пароль қолданыңыз.
4. Терминалда орындаңыз:

```bash
npm install
npm start
```

5. Браузерден **http://localhost:3000** ашыңыз.

Егер 3000 порт бос болмаса, `.env` ішіне `PORT=3001` қойып, http://localhost:3001 арқылы ашыңыз.

## Не жұмыс істейді?
- Басты бет: дерекқордағы нақты көрсеткіштер.
- Абоненттер: тізім, қосу, статусын өзгерту.
- SIM тіркеу: абонентке бос SIM тіркеу.
- Тарифтер: SIM-ке алғашқы тарифті қосу және тарифті өзгерту (өзгерістер тарихы сақталады).
- Шот: айға есеп шығару, төлем қабылдау (PL/pgSQL функцияларымен).
- Аналитика: танымал тарифтер, ARPU, ең көп интернет пайдаланғандар.
- 15 кесте: барлық кестелердің соңғы 100 жазбасын қарау.

**Шектеу:** бұл оқу демонстрациясы. Интернет/қоңырау тұтынуы тест деректерінен оқылады. Нақты оператор биллингі, жүйеге кіру/рөлдер, толық CRUD, SMS шамадан асу есептеуі және қауіпсіз өндірістік деплой іске асырылмаған. Сайтты интернетке ашық жарияламаңыз: API-де аутентификация жоқ.
